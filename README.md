## 🧰 Tech stack of the portfolio itself

- **Vanilla HTML / CSS / JavaScript** — no frameworks, no build step, no dependencies
- **Warm dark theme** — charcoal background with amber/terracotta accents, high-contrast text for readability
- **Zero frameworks** — custom CSS custom properties, hand-rolled components
- **Static hosting friendly** — plain file structure works on GitHub Pages

## 🚀 Running locally

```bash
git clone https://github.com/abdullahkhaledfawzi/portfolio.git
cd portfolio
python3 -m http.server 8080
# then open http://localhost:8080
```
